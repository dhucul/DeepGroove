What changes

Adaptive ladder instead of five fixed levels. Steps coarsen toward the centre line as the linear scale compresses: 1 dB → 3 → 6 → 12 → 24. A level is drawn only where its own neighbour spacing clears the minimum gap.
The scale no longer empties out when you zoom. At ×4 amplitude zoom 0 dB is off-screen and today only −12 and −24 remain; the ladder fills in −13…−21 and reaches −30/−36.
Both halves are labelled. Today only the upper half carries numbers — the lower ticks are anonymous.
Major / minor ticks. Labelled levels get a 7 px tick in the normal tick colour; unlabelled levels get a 4 px faint tick, so the ladder reads as a ruler rather than a stack.
−∞ names the centre line. The middle of the band is a reserved label slot, so no number is ever crushed against it — the one level the scale never named.
Unchanged: column width, fonts, colours, and the waveform's own grid lines (still 0/−3/−6/−12/−24, so the wave doesn't get busier).
