Recording Level Assistant — one-click Apply, target ceiling, device memory
The assistant already computes an exact device-level + fine-trim plan; today it only prints it and you match two sliders by hand. These are the visible changes: an Apply button inside the existing SAFE SETTING box, a configurable target ceiling (replacing the hard-coded −3 dBTP), and a device-memory row you can act on instead of only read. Nothing else in the Record dialog moves.

4 · Target ceiling — Settings ▸ Recording

Replaces the hard-coded −3 dBTP. Default moves to −6 for transfer work: declicking and peak reconstruction can put repaired peaks back above what was captured, and −3 leaves almost nothing for that. Existing users see recommendations about 3 dB more conservative than before.
RECORDING TARGET CEILING
−3 dBTP −6 dBTP −10 dBTP
Peak the Recording Level Assistant aims a transfer at. −6 dBTP suits vinyl and tape transfers that will be declicked or restored afterwards. −3 dBTP is the previous behaviour. −10 dBTP is for sources you expect to need heavy repair.
