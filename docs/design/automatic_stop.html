BEHAVIOUR THIS MOCKUP ASSUMES

  • Threshold is relative, not absolute. Run-out is decided by RecordingLevelAnalyzer's existing programme-vs-noise-floor classifier, learned from the first seconds of the take — not a fixed dBFS gate. Surface noise, hum and rumble therefore do not hold the recording open.
  • 12 s default hold. Long enough to sit through an inter-track gap or a quiet passage; short enough that the tail is not minutes of run-out. Range 5–60 s.
  • The trim point is the last programme block plus 2 s, captured when the hold starts — so the discarded run-out never reaches the document, but a natural fade tail is kept.
  • Options lock at capture start. Same rule the needle-drop checkbox already follows; the panel greys out while recording or armed.
  • The duration cap is independent. It fires from elapsed capture time alone, so a detector that never triggers still cannot run the disk to the existing MaxCaptureBytes ceiling.
  • Both settings persist to %AppData%\WaveLab\settings.json via AppSettings, like the other record options.
