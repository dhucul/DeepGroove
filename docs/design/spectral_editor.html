Spectral editor — seeing and repairing what the waveform cannot show

The spectrogram today is a fixed 1024-point, 800×256 image of the current view, downmixed to mono, in a 252 px analysis tab, with no mouse handling of any kind. This makes it an editing surface: it moves into the main editor area on the same time axis as the waveform, gains a frequency selection, and gains the repair actions the DSP for which already exists.

How it works

It lives in the editor, not the analysis tab. A 252 px tab is a readout; editing needs canvas. Waveform / Split / Spectrogram share one time axis, one zoom, one playhead and one transport, so the overview bar, time ruler, markers and selection all keep working exactly as they do now.
The left gutter changes with the view. The dBFS ladder stays beside the waveform; the spectrogram gets a logarithmic frequency ruler on the same adaptive-step principle, so it thins out rather than crowding when the pane is short.
Selection gains two dimensions and a channel. Today it is SelStart/SelEnd and nothing else. It becomes a time span, a frequency band, and which channels it applies to — with the existing time-only behaviour intact when the waveform has focus, so nothing that works today changes.
Four ways to select, because defects have shapes. A rectangle suits a thump; a lasso follows a swept squeal; the wand grows through connected energy for a cough; harmonic selection takes a fundamental and its partials together, which is what a buzz actually is.
Heal is the flagship action. Inside the selection the audio is reconstructed from what surrounds it — the same principle as the de-click repair already shipped, extended to a region of the spectrogram. Attenuate and Gain are the gentler cousins for when removal would be too much.
Reassignment is what makes it sharp. Each bin is relocated to its own centre of energy, so partials appear as lines rather than bands. It costs two extra transforms per frame and is a toggle, because for reading noise floors the unsharpened view is easier.
Perceptually uniform colour by default. Viridis does not invent contours where the data is smooth, which the usual heat ramps do. The house teal remains available; both are stated in dB with the range on screen rather than left implicit.
Edits stay undoable and bounded. A repair renders back to the time domain over the affected span with warm-up lead-in, then commits through the same single ReplaceRange splice every other edit uses — so it undoes in one step and autosaves like anything else.
