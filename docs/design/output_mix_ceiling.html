Output mix — saying what the blend costs every stage

The mix is applied once, to the whole chain output, so the dry share it returns is a hard ceiling on what any stage can achieve: at the shipped 90 % default nothing can be reduced by more than 20 dB, however well it works. A 30 Hz high-pass that measures 40 dB at 10 Hz lands at 19.7. One line under the slider states it.
Card drawn at the dialog's 860 px minimum. Widths below are measured from the built control — OutputMixRenderProbe reports 330 px of room for the line and 282 px wanted by the widest wording, on one 13 px row. The column arithmetic had said 339, out by the width of a scroll bar.

No colour on the figure being a fact. The ceiling is not a fault, so it is drawn Muted like the declip and noise-depth readouts, with the number in accent. Amber appears only on Bypassed, which is a state where the control genuinely does nothing — the repo's own rule that colouring a fact like a fault teaches users to distrust the colour.

The line is bounded. The mix is 0–100, so the ceiling runs 0.0 dB to ∞ and the widest wording is the one drawn. Nothing a user can set pushes the sentence off the card.

The default is untouched. 90 % stays the shipped value; this proposal only says out loud what it costs. Changing the default to 100 is a separate decision and a separate one-line change.
